# Reproductor

Reproductor de vídeo local para Android 16 (API 36), con diseño Material 3 Expressive.

- La app se abre en vertical; los vídeos se reproducen en horizontal.
- Kotlin + Jetpack Compose + Media3 (ExoPlayer).
